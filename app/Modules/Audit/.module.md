# Módulo `Audit`

| | |
|---|---|
| **Capa** | `kernel` |
| **Activable por tenant** | No |
| **Iteración** | 1 (ARQUITECTURA_MAESTRA §14) |
| **Estado** | Carpetas canónicas creadas, sin código. Se implementa en la Iteración 1. |

## Alcance

Bitácora técnica inmutable: actor, acción, entidad, antes y después, IP y terminal. Junto con los payloads de impresión, la única tabla del proyecto con columnas JSON permitidas. Retención de 12 meses en caliente más archivado (D47).

## Reglas de frontera (ARQUITECTURA_MAESTRA §2)

- Puede depender del shared kernel. El kernel no depende de este módulo.
- Los efectos sobre otros módulos viajan **sólo** por eventos de dominio, nunca por escritura directa.
- Expone públicamente los servicios de `Application/`, los eventos de `Events/` y los listeners que registra. Todo lo demás es privado del módulo.
- Toda tabla propia lleva `tenant_id` NOT NULL y todo modelo propio lleva el global scope de tenant (ADR-002).
- Toda entrada pasa por Form Request; toda salida por Resource; los filtros van en whitelist.

## Estructura canónica

```
Audit/
├── Domain/          # entidades, reglas, value objects, máquinas de estado
├── Application/     # servicios de caso de uso, DTOs
├── Infrastructure/  # modelos Eloquent, repositorios, adaptadores
├── Http/            # Controllers, Requests, Resources, Routes
├── Events/ · Listeners/ · Jobs/
├── Providers/
└── database/        # migrations y seeders del módulo
```
